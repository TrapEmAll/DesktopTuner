# StartAllBack parity tracker

This tracker uses StartAllBack's public product description as the baseline. Its official page currently advertises a classic-style Start menu, a redesigned taskbar, File Explorer and Control Panel styling, context-menu changes, and cross-app visual consistency. The detailed list below is an implementation target, not a claim that each item has equal internals or exact visual fidelity.

| Area | StartAllBack capability | Desktop Tuner status |
|---|---|---|
| Start | Search and launch apps | Partial: companion launcher ranks exact, prefix, word-boundary, and substring matches across Start-menu app and folder names, plus `shell:AppsFolder` apps; unmatched Enter searches hand off through Windows' `search:` protocol, and explicit Windows Search and web search actions are available; `Ctrl+Alt+Space` and optional Windows-key replacement with Win+key passthrough work; authentic Windows Start integration remains |
| Start | Classic menu styles and system-place shortcuts | Partial: Modern, Classic two-column, and Compact layouts with persistent, reorderable pinned-app favorites, nested Start-menu folders, Documents, Downloads, Settings, This PC, Control Panel, Network, media-folder, and Recent shortcuts, plus Lock, Sleep, Hibernate, Sign out, Restart, and Shut down actions with confirmation for session-ending actions; authentic Win7/8 styling remains |
| Taskbar | Classic/replacement taskbar and edge placement | Partial: live overlays on the primary display or all connected displays, with per-display placement, window switching, and optional sign-in startup; native taskbars remain underneath |
| Taskbar | Labels, icon size, margins, grouping, drag/drop | Partial: optional window labels, extracted app icons with three icon sizes, compact/standard/relaxed button spacing, centered or left-aligned app buttons while Start stays left, persistent reorderable launch pins, current-session reorderable running-window buttons shared across displays, active-window second-click minimize, executable/shortcut/folder drag-and-drop, document-to-app drop, and three bar sizes/grouping preference exist; native taskbar integration remains |
| Taskbar | Segmented/floating/translucent styles and auto-hide | Partial: adjustable 0–70% overlay transparency, edge-aware idle auto-hide with a Win+Alt+T toggle, optional hide when a maximized app covers each display, floating inset style, and separate Start/apps/system segments; dynamic aura effects and Windows material blur remain |
| Taskbar | Tray, taskbar context menus, widgets, flyouts, and multi-monitor behavior | Partial: running-window buttons open delayed hover previews with clickable DWM thumbnails and per-window close buttons; grouped minimize/close commands, rounded palette-aware menus shared with Start and Explorer, a button that opens the native Widgets board, and default-output volume/mute controls are available; on supported bottom edge-to-edge and segmented layouts, the overlay stops at the detected native notification-area boundary so Windows' tray icons, clock, and flyouts remain visible and clickable; other layouts retain Tray and Clock shortcuts; native menu acrylic, device selection, and additional shell flyouts remain |
| Explorer | Restyled ribbon/command bar and translucent menus | Partial: companion Desktop Tuner Explorer has multi-tab folder browsing, multi-select cut/copy/paste and Recycle Bin deletion, a classic command strip, folder/file operations, and clickable Name/Date/Type/Size sorting; native File Explorer restyling and translucent menus remain |
| Explorer | Bottom details pane and classic search | Partial: companion Desktop Tuner Explorer has a resizable, hideable bottom details pane and recursively searches the current folder tree by name; changing native File Explorer's pane placement and search visuals remains |
| Explorer | Folder defaults and legacy view options | Partial: Home/This PC startup, file-extension and hidden-item visibility, compact spacing, full-path title bars, separate folder processes, and companion Explorer quick-access folders that honor startup/hidden-item/extension preferences; modern native ribbon/command-bar styling and bottom details-pane placement remain |
| Explorer | Dark mode and common-dialog styling | Partial: companion Start and Explorer windows now follow Windows' app light/dark mode live, alongside the shared system color and transparency settings; dark styling for Windows common dialogs and Control Panel remains |
| Explorer | Context-menu appearance and behavior | Partial: rounded, live light/dark palette-aware context menus in the companion Start, taskbar, and Explorer surfaces plus the per-user classic full-menu switch; native Windows menu styling and acrylic remain |
| Shell-wide | Classic applet behavior, fonts, colors, and UI consistency | Missing |
| Reliability | Windows-version compatibility, recovery and resource discipline | Partial: user-level setting snapshots, apply rollback, and opt-in per-user sign-in startup exist; build matrix, updater, installer, and telemetry-free resource profiling remain |

The current Windows App SDK and Win32 documentation do not provide public APIs for replacing the system taskbar or arbitrary built-in Start-menu visuals. Reaching behavioral parity in those areas will require compatibility-tested shell integration and a Windows-build test matrix; registry toggles alone do not meet the objective.
