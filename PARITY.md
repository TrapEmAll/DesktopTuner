# StartAllBack parity tracker

This tracker uses StartAllBack's public product description as the baseline. Its official page currently advertises a classic-style Start menu, a redesigned taskbar, File Explorer and Control Panel styling, context-menu changes, and cross-app visual consistency. The detailed list below is an implementation target, not a claim that each item has equal internals or exact visual fidelity.

| Area | StartAllBack capability | Desktop Tuner status |
|---|---|---|
| Start | Search and launch apps | Partial: companion launcher loads Start-menu shortcuts and `shell:AppsFolder` apps on a background STA thread to keep the launcher responsive, ranks exact, prefix, word-boundary, and substring matches across app and folder names, groups the all-apps list with alphabet markers and a `#` section for numeric or symbol prefixes, and displays shell-extracted icons where available; context menus can open the source folder for existing desktop shortcuts and executables or launch them through Windows UAC, while packaged Windows apps are not offered elevation; unmatched Enter searches hand off through Windows' `search:` protocol, and explicit Windows Search and web search actions are available; `Ctrl+Alt+Space` and optional Windows-key replacement with Win+key passthrough work; authentic Windows Start integration remains |
| Start | Classic menu styles, system-place shortcuts, and dropdown navigation | Partial: Modern, Classic, Windows 7-inspired two-column, and Compact layouts with persistent pinned-app favorites that can be added by dragging from app search/all-apps or the Classic folder tree, dropping `.lnk` shortcuts or `.exe` files from Explorer or the desktop, or using context menus, and reordered by drag-and-drop or context menu, plus shell-extracted app icons, nested Start-menu folders, and lazy, bounded Documents/Downloads/Music/Pictures/Videos flyouts for files and two levels of folders; Settings, This PC, Control Panel, Network, Recent, and Run shortcuts; Lock, Sleep, Hibernate, Sign out, Restart, and Shut down actions with confirmation for session-ending actions; authentic Win7/8 styling remains |
| Taskbar | Classic/replacement taskbar and edge placement | Partial: live overlays on the primary display or all connected displays, with per-display placement, a dedicated Windows Search button, window switching, optional sign-in startup, and an opt-in replacement mode that hides Windows taskbars only on covered displays, monitors for Explorer-created replacements, and restores each captured taskbar visibility state on normal or unexpected app exit; deep Explorer integration and the native Start/taskbar relationship remain |
| Taskbar | Labels, icon size, margins, grouping, drag/drop | Partial: optional window labels, extracted app icons with three icon sizes, compact/standard/relaxed button spacing, centered or left-aligned app buttons while Start stays left, persistent reorderable launch pins with Win+1–9 launch shortcuts and Win+T keyboard taskbar focus when Windows-key integration is enabled, pins absorb matching running executable windows including shortcut targets, folder pins browse up to 20 visible children per level across two nested folder levels from a lazy context-menu flyout and can open locations in File Explorer, subtle running and accent active-state indicators, current-session reorderable unpinned-window buttons and drag-reorderable DWM preview cards shared across displays, active-window second-click minimize, middle-click close of the foreground window in a group, executable/shortcut/folder drag-and-drop, document-to-app drop, and three bar sizes/grouping preference exist; native taskbar integration remains |
| Taskbar | Segmented/floating/translucent styles and auto-hide | Partial: adjustable 0–70% overlay transparency with an adaptive mode that applies the selected transparency while a maximized app covers a display and returns to a solid surface on the desktop, taskbar accents that follow the current Windows DWM colorization color, optional Aero-style Aura highlights sampled from app-icon colors with a Dynamic Aura spotlight that follows the pointer, edge-aware idle auto-hide with a Win+Alt+T toggle, optional hide when a maximized app covers each display, floating inset style, and separate Start/apps/system segments; Windows material blur remains |
| Taskbar | Tray, taskbar context menus, widgets, flyouts, and multi-monitor behavior | Partial: running-window buttons open delayed hover previews with clickable DWM thumbnails, Acrylic-backed host surfaces where supported, and per-window close buttons; grouped minimize/close commands, rounded palette-aware menus with DWM Desktop Acrylic where supported, buttons that open native Widgets and Task View and send Win+D to show the desktop, and default-output volume/mute controls with output-device selection are available; replacement mode adds a regional-format-aware clock, a Quick Settings button for the native Win+A panel, and battery level, charging state, and remaining time when Windows reports a battery, linking to Power settings; when the custom bar shares an edge with the native taskbar, the overlay stops at the detected notification-area boundary on bottom, top, left, or right edges so Windows' tray icons, clock, and flyouts remain visible and clickable; device selection uses an undocumented Windows policy COM interface with Sound settings fallback; native shell flyouts remain |
| Explorer | Restyled ribbon/command bar and translucent menus | Partial: companion Desktop Tuner Explorer has a DWM Mica window backdrop, multi-tab folder browsing with per-tab Details/List/Small icons/Medium icons/Large icons/Tiles layouts and sort preferences saved per folder across sessions, shell file/folder icons and drag-to-reorder tabs, middle-click folder or drive rows to open them in new tabs, tab context actions to duplicate the selected tab with independent copied navigation history, layout, and sorting, close the current tab, close other tabs, or close tabs to the right, middle-click tab close with Ctrl+Shift+T restoration of the last ten tabs closed in the current window including their navigation history, drag-to-folder file transfers with same-volume move/cross-volume copy defaults and Ctrl/Shift overrides, multi-select cut/copy/paste and Recycle Bin deletion, a native Windows Properties sheet for a single selected file or folder, a Home/Share/View command ribbon with selection-aware open, new-tab, copy-path, file operations, sort-column/direction, and details-pane controls; clickable Name/Date/Type/Size sorting; native File Explorer restyling remains |
| Explorer | Bottom details pane and classic search | Partial: companion Desktop Tuner Explorer has a resizable, hideable bottom details pane that summarizes multi-file/folder selections, common locations, known combined file sizes, and modified dates, plus recursive current-folder search with quoted phrases, filename wildcards, extension and file-kind filters, inclusive modified-date bounds, and binary size comparisons; changing native File Explorer's pane placement and search visuals remains |
| Explorer | Folder defaults and legacy view options | Partial: Home/This PC startup, a Home page of recent files that honors Windows' recent-items privacy setting, clickable location breadcrumbs with Ctrl+L/Alt+D direct path entry, file-extension and hidden-item visibility, compact spacing, full-path title bars, separate folder processes, companion Explorer quick-access folders that honor startup/hidden-item/extension preferences and support persistent user-pinned folders by drag-and-drop or context menu with drag reordering, an asynchronous expandable navigation tree for the user folder and available drives that follows the active folder while browsing, respects hidden-item visibility, and skips reparse points, and optional per-tab This PC drive grouping by hard disk, removable, optical, network, and other drive type with free-space bars and capacity summaries in all layouts; modern native ribbon/command-bar styling and bottom details-pane placement remain |
| Explorer | Dark mode and common-dialog styling | Partial: companion Start and Explorer windows follow Windows' app light/dark mode live, while the Desktop Tuner settings and Explorer title bars use the Windows 11 DWM dark-mode frame when system dark mode is enabled; dark styling for Windows common-dialog contents and Control Panel remains |
| Explorer | Context-menu appearance and behavior | Partial: rounded, live light/dark palette-aware context menus in the companion Start, taskbar, and Explorer surfaces use DWM Desktop Acrylic and small DWM-rounded corners where supported, with a solid themed fallback; the per-user classic full-menu switch remains, as does native Windows menu styling |
| Shell-wide | Classic applet behavior, fonts, colors, and UI consistency | Partial: companion Start and Explorer follow Windows app light/dark mode and accent color, while the custom taskbar and its window previews follow system light/dark mode and accent color live; native Win32 app recoloring, classic applet behavior, and shell-wide font styling remain |
| Reliability | Windows-version compatibility, recovery and resource discipline | Partial: user-level setting snapshots, apply rollback, opt-in per-user sign-in startup, and a per-user Windows installer exist; build matrix, updater, and telemetry-free resource profiling remain |

The current Windows App SDK and Win32 documentation do not provide public APIs for replacing the system taskbar or arbitrary built-in Start-menu visuals. Reaching behavioral parity in those areas will require compatibility-tested shell integration and a Windows-build test matrix; registry toggles alone do not meet the objective.
