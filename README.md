# Desktop Tuner

A native Windows 11 desktop-personalization starter focused on the Start menu, taskbar, and File Explorer.

## What works in this build

- In replacement mode, separate Network and Emoji buttons open Windows' Wi-Fi settings and native emoji panel alongside the native Quick Settings shortcut.
- When Desktop Tuner draws its own notification area, an optional microphone button adjusts the default capture level with the mouse wheel, toggles mute with middle-click, and lists active input devices on right-click. It is hidden when Windows has no default input endpoint, and its click opens Sound settings.
- Choose which custom taskbar system buttons appear, including Search; hidden controls release space for open app buttons, and older preference files keep the full default control set.
- Choose an apps-only dock style that centers running and pinned app buttons in a translucent capsule while leaving Start and system controls separate; transparent space stays clear of the taskbar-wide backdrop.
- Choose Windows 11, Windows 10, or Windows 7-inspired Aero taskbar visuals independently of the bar layout. The classic presets use their own palette, square-edged controls, and surface treatment while keeping the selected taskbar transparency and app-button preferences.
- In replacement mode, edge-docked taskbars register with the Windows AppBar API so maximized windows honor their reserved work area, full-screen apps can cover them, and Windows can coordinate their activation and z-order; replacement mode restores the native taskbar if Windows refuses the reservation. Floating bars remain overlay-only. See [SHELL-INTEGRATION.md](SHELL-INTEGRATION.md) for shell-integration limits and validation notes.
- When replacement-mode auto-hide is enabled, edge-docked taskbars also register that monitor edge with Windows and release it when disabled or closed; if the edge is already claimed, Desktop Tuner keeps its local auto-hide behavior.
- In the companion Explorer, mouse side buttons navigate Back and Forward through the current tab's folder history, alongside the toolbar and Alt+Left/Alt+Right shortcuts.
- Optionally add per-user “Open with Desktop Tuner” commands to filesystem-folder and empty-folder context menus. Opening a folder routes it to the existing app instance or creates an Explorer tab; Windows' default folder handler stays unchanged outside shell-host mode. A supervised shell-host session temporarily owns the per-user folder default and restores the previous verb when it exits. Windows 11 may place these legacy shell commands under Show more options.

- Includes a native `IExplorerCommand` bridge and sparse identity manifest for Windows 11's modern folder context menu. CI builds the bridge and validates the package manifest; normal installation is pending a trusted publisher signing certificate, so the existing legacy menu commands remain active. See [SHELL-INTEGRATION.md](SHELL-INTEGRATION.md) for the signing and runtime-validation steps.
- Opens a searchable Start-style app launcher from Ctrl+Alt+Space or the Start settings page. It indexes the user's and shared Start menu shortcuts plus Windows AppsFolder applications on a background STA thread, keeping the launcher responsive while Windows supplies the catalog; results show each app’s shell icon where available. Search ranks exact names and prefixes first, then word-boundary and substring matches, with a bounded typo-tolerant fallback for longer terms. Context menus can open the source folder for an existing desktop shortcut or executable, or launch one as administrator through the Windows UAC prompt, while packaged Windows apps remain at their normal privilege level. Unmatched Enter searches hand off to Windows Search, and separate Windows and Web buttons let users explicitly broaden any query. The More places menu includes lazy, nested Documents, Downloads, Music, Pictures, and Videos flyouts for opening files and folders directly, alongside Settings, This PC, Control Panel, Network, Recent items, and the classic Run dialog. The Control Panel entry has a flyout for opening Control Panel or launching 27 classic applets and canonical items directly, including Bluetooth Devices, Add Hardware, Game Controllers, Tablet PC Settings, Network and Sharing Center, Internet Options, Credential Manager, Security and Maintenance, and Ease of Access Center. Start settings let you hide and reorder applet shortcuts; direct `.cpl` entries appear only when the corresponding module is installed. Windows may still redirect or omit some items depending on its version and edition.
- Customize the Start menu's system-place shortcuts from the Start settings page: hide places you do not use and reorder the remaining links. The More places menu applies the selection immediately and keeps the dropdowns for nested Documents, Downloads, Music, Pictures, and Videos browsing.
- Open the Windows Recycle Bin from the Start menu's configurable More places list. Existing saved place settings keep their current order and visibility; the newly added shortcut is enabled by default and can be hidden or moved from Start settings. The companion Explorer also browses Recycle Bin items, restores them to their original folders, and supports confirmed permanent deletion.
- Offers Modern, Classic two-column, Windows 7-inspired two-column, Windows 8-inspired pinned-tile, and Compact launcher layouts, with the selected style saved between sessions. The Windows 7-inspired layout places search below the program list, uses a compact two-column blue system-places panel, and shows the current account name with its local Windows account picture when available or initials otherwise. The Windows 8-inspired layout displays pinned apps in an accent-colored tile grid above the all-apps list. The all-apps list uses alphabet markers and a `#` section for names that begin with digits or symbols. Pin shortcuts and packaged Windows apps by dragging from the app list or Classic folder tree, dropping `.lnk` shortcuts or `.exe` files from Explorer or the desktop, or using an app context menu; folders can be pinned by dropping them from Explorer or the desktop and opened from their Start tile. Pins persist and can be reordered by dragging or through each pinned app’s context menu. The empty favorites area remains a drop target. The Classic layouts browse nested Start-menu program folders and packaged Windows apps. In shell-host mode, an app's Open file location command opens the shortcut's parent folder in companion Explorer and selects the shortcut. The power menu provides Lock, Sleep, Hibernate, Sign out, Restart, and Shut down, with confirmation for actions that can close the session.
- Optionally opens the custom launcher when the user taps either Windows key; while a custom taskbar is running, Win+1 through Win+9 activate the matching pinned app. Modified shortcuts still pass through to Windows, and the setting is disabled by default.
- Optionally routes Win+E to the companion File Explorer while Desktop Tuner is running. The preference is off by default, bare Windows-key taps still open native Start unless Start replacement is separately enabled, and Windows Explorer remains available from the taskbar and other apps.
- Shows a configurable 0–12 recently launched, unpinned apps in the Start menu using a local history file; a Clear action removes that history.
- Adds a Windows 10-inspired Start layout with the app list beside a scrollable pinned tile grid. In the Windows 8 and 10-inspired layouts, pinned apps can be organized into named groups that users can create, rename, and reorder by moving apps from tile context menus or dropping them onto a group heading. Each pinned app also supports a saved Small, Medium, Wide, or Large tile size.
- Optionally centers the Start menu along the selected taskbar edge, including on scaled and secondary displays.
- Opens a taskbar overlay on the primary display or every connected display, with live top-level window switching, second-click minimize/restore behavior, middle-click close for the foreground window in a grouped button, and middle-click launch of a new instance from a pinned app button; pinned context menus also expose Start new instance. It provides delayed hover previews with clickable, drag-reorderable DWM thumbnails, per-window close buttons, and taskbar and preview hosts that request DWM Desktop Acrylic where supported. Unsupported backdrop hosts retain their existing theme and transparency. An opt-in experimental replacement mode hides Windows' built-in taskbar on displays covered by Desktop Tuner, watches for Explorer-created taskbars, and restores captured taskbar visibility states when the custom taskbar closes or the app exits unexpectedly through a companion recovery process. It also provides per-window and grouped minimize/close commands, and rounded context menus that follow the shared light/dark palette and use DWM Desktop Acrylic where supported; touch screens get 44-DIP menu-item hit targets while pointer input keeps compact spacing. Running windows for pinned executables or shortcut targets share the pinned button and show a running indicator instead of appearing twice; the foreground app uses the accent indicator by default, or an optional Aero-style Aura sampled from each app icon, with Dynamic Aura following the pointer. Other reorderable running-window buttons are shared across displays for the current session. The Start button opens the companion Start menu on that display, and a Search button opens native Windows Search with Win+S. With Windows-key replacement enabled, Win+T focuses the custom taskbar, repeated Win+T or arrow keys cycle its buttons, and Escape returns to the previous app. Toggle idle auto-hide globally with Win+Alt+T. When the custom bar shares an edge with the native taskbar, it stops at the detected notification-area boundary on bottom, top, left, and right edges so tray icons, clock, and flyouts remain visible and clickable; replacement mode instead provides the companion Tray and Quick Settings buttons, a keyboard-layout picker (Win+Space) and On-Screen Keyboard button (Win+Ctrl+O), and a clock that follows the user's regional time and date formats, with its context menu linking to Date and time and Notification settings, audio controls (scroll to adjust volume, middle-click to mute, right-click to choose an output device, click for Sound settings), battery status with Quick Settings on click and a direct Power & battery settings link from its context menu on devices that have a battery, and a Desktop button. The custom Network button also opens Quick Settings on click and keeps direct Network & Internet settings in its context menu when Explorer's native notification area is absent. In shell-host mode, Win+D and that button minimize ordinary windows while keeping Desktop Tuner's desktop and bars visible, then restore the windows minimized by that toggle. Quick Settings opens Windows' native Win+A panel for controls such as Wi-Fi, Bluetooth, brightness, and volume. Output switching falls back to Windows Sound settings if the system policy interface is unavailable. A Widgets button opens the native Windows Widgets board, and Task View opens with Win+Tab. Optional per-user sign-in startup launches the taskbar in the background. Taskbar transparency can adapt to the current desktop state, becoming solid on the desktop and using the selected transparency under a maximized app. Buttons can show extracted app icons at three sizes, hide or show labels, adjust their spacing, and center while Start stays left. Edge, size, transparency, full-edge, floating, segmented, display coverage, auto-hide, replacement preferences persist between app launches.
- Choose whether running app windows appear on all custom taskbars, only on the taskbar for the display Windows assigns to each window, or on that display and the primary taskbar. Windows' monitor assignment handles windows spanning displays, and pinned launch buttons stay available on every custom taskbar. Running windows are filtered to the active Windows virtual desktop by default, with an option to show windows from every desktop. Taskbars share a short-lived top-level window snapshot across displays to avoid repeating window and process-metadata scans during closely timed refreshes.
- Pins running desktop apps to the custom taskbar, or drag `.exe` files, `.lnk` shortcuts, and folders onto it. Replacement-desktop Shell items such as This PC, Network, Control Panel, and Recycle Bin can also be pinned from their context menus; their native Shell icons persist with the pin and launching them passes the parsing name to Explorer. Supported Shell pins can round-trip between the taskbar and replacement Start menu. Drag pinned buttons to reorder them; Ctrl-drag a folder onto an app pin to add a persisted Pinned destinations Jump List entry, and choose it from the pin context menu to open it. Pinned buttons activate or launch apps and shortcuts, or open folders in File Explorer. Folder pins also provide an on-demand context-menu browser for up to 20 visible items per level and two nested folder levels. Pinned app and folder context menus can open the target's location; shell-host mode routes that action into companion Explorer, selecting executable and shortcut targets in their parent folder, and missing targets disable it. Jump List filesystem folders and Shell namespace locations also stay in companion Explorer. Drop documents onto a pinned app to open them there; pins persist between app launches.
- Opens a companion File Explorer with a Home landing page for recently opened files, shell icons beside files and folders, an expandable navigation tree for the user folder and available drives, clickable location breadcrumbs with lazy child-folder dropdown menus and Ctrl+L/Alt+D switching to direct path entry, drag-to-reorder tabs within a window or move them between open Explorer windows, and drag-to-move files between folders or out to other apps. The navigation tree loads one level at a time in the background, expands and selects the active folder reached through any navigation method, respects hidden-item visibility, skips reparse-point folders to avoid loops, and reports access errors without freezing the window. Open tabs, the selected tab, each tab's view and sort choices, navigation/search history, the details pane's visibility and height, and the folder-opening preference restore on the next normal launch; explicit folder and This PC launches take precedence. A tab context menu can duplicate the selected tab with its navigation history, layout, and sort preferences, close that tab, close other tabs, or close tabs to its right. When more than one tab is open, middle-click a tab to close it; Ctrl+Shift+T restores one of the last ten tabs closed in that Explorer window, including its navigation history. Middle-click a folder or drive row to open it in a new tab; Ctrl+N opens the current location in a separate window, and a selected folder can open there from the Share ribbon or context menu. Additional windows use the same folder-view preferences without replacing the primary window's saved tabs. Drop onto a folder row to transfer there or onto empty space to transfer into the current folder; same-volume drops move by default, cross-volume drops copy, and Ctrl/Shift select copy/move. Switch each tab between Details, List, Small icons, Medium icons, Large icons, and Tiles; new tabs inherit the current layout. Each tab retains its own sort column and direction; view, sort, and resizable widths for all six Details columns are saved per folder and restored in future sessions. Per-tab navigation and search history, Ctrl+T/Ctrl+W/Ctrl+Tab tab shortcuts, Ctrl+L/Alt+D address focus, Alt+Up parent-folder navigation, Alt+Left/Alt+Right history navigation, Ctrl+F search focus, F6/Shift+F6 pane navigation, and a View option to open folders in new tabs from Open, double-click, or Enter are included. It also has a Home/Share/View command ribbon for selection-aware file actions, sort direction, and the details pane; Show more options opens Windows' native Shell context menu for the selection or folder background, retaining installed file verbs and supporting multi-select when items share a parent folder; direct Open with, Print, Share, and Copy as path commands are available for supported selections. The Explorer also has quick access to common folders and drives, persistent user-pinned folders by right-clicking or dragging folders into Quick Access, single-selection Pin to Start and Pin to taskbar commands for folders, .exe, and .lnk launch targets, with drag-to-reorder support, recursive file-name, plain-text content, and metadata search with quoted phrases and filename wildcards; `content:"phrase"` searches supported text files up to 16 MiB and reports unsupported or oversized formats, while `ext:`/`kind:` filters, inclusive `after:`/`before:` modified-date bounds, and binary `size:` comparisons such as `size:>=10MB` further refine results. Sortable Name, Date modified, Type, Size, Date created, and Date accessed columns, and a two-row bottom details pane that shows type, location, size, and modified/created/accessed dates for single items, plus common locations, known combined file sizes, and shared or differing dates for multi-selections; it can be hidden or resized. This PC groups hard disks, removable storage, optical drives, network locations, and other drive types, with per-tab control over grouping, and shows free-space bars with available and total capacity in every layout. Select one or more files or folders to open native Windows Properties from the context menu; Alt+Enter opens the same sheet for the current selection. On supported Windows builds it requests the DWM Mica backdrop, falling back to its solid theme when unavailable. Select multiple files or folders and cut, copy, paste, or send them to the Recycle Bin with the toolbar, context menu, or keyboard shortcuts; cut items are dimmed until moved and delete reports individual failures. It follows the app's Windows preferences for startup location, hidden items, and file extensions. Create folders, rename items, and refresh from the toolbar or context menu; F2 opens an in-place name editor with the extension excluded from the initial selection; Enter commits, Escape cancels, and folders and files without extensions are selected in full; Delete, F5, and Ctrl+Shift+N are also supported. Double-click folders to browse and files to launch with their default app.
- Adjusts twenty-one per-user Windows settings across Start, taskbar, and File Explorer, including taskbar sizing, clock seconds, Show desktop, Task View, Widgets, and search presentation, full-path title bars, separate Explorer folder processes, always-visible scrollbars, notification-area icon visibility, and app/system color modes and transparency preferences. The replacement taskbar can hide its search control or show a button or box. Some legacy Explorer preferences may be ignored by current tabbed File Explorer builds. Appearance settings are shared with Windows and can affect other apps and shell surfaces.
- The companion Start launcher and File Explorer follow the selected Windows app color mode and system accent color. The Desktop Tuner settings window uses the same live light/dark palette for its background, navigation, cards, and controls, and requests a DWM Mica backdrop with its themed solid background as a fallback. The custom taskbar background menu includes direct Task Manager, Show the desktop, and Lock the taskbar commands; Taskbar settings expose the same lock control for disabling pin and window reordering and a Windows-compatible toggle for showing seconds in the taskbar clock. The custom taskbar and its window-preview cards follow Windows system light/dark mode and accent color and update when those settings change. On Windows 11, the Desktop Tuner settings and Explorer title bars also track the system dark-mode setting through DWM.
- Saves and imports portable JSON profiles. Import loads choices for review and never applies them automatically.
- Captures the exact prior registry values before applying and provides one-step undo for the last successful apply.
- Rolls back partial registry writes if an apply fails.
- Does not inject code into Explorer or require administrator privileges.

Explorer compatibility settings include a confirmed Restart Windows Explorer action so context-menu and legacy view changes can be applied immediately. The taskbar overlays leave the native Windows notification area exposed on supported bottom layouts; this depends on locating undocumented Shell window classes and falls back to shortcut controls if they are unavailable. Replacement mode is experimental; a companion process restores the native taskbar on unexpected app exit. If both Desktop Tuner and its watchdog are terminated, the next single-instance launch restores any abandoned taskbar visibility snapshot. Appearance follows each display's effective DPI. Windows display-change notifications are coalesced before taskbar windows are reconciled, but mixed-DPI and hot-plug behavior still needs manual validation. Some Windows registry preferences and the classic context-menu switch may vary across Windows builds. Start's recent-items option is a Windows privacy setting shared with Jump Lists and File Explorer. Reproducing authentic native taskbar/Start integration and Explorer styling remains parity work.

See [PARITY.md](PARITY.md) for the feature-by-feature gap list against StartAllBack's current public feature description.

## Build

Requires the .NET 10 SDK and Windows Desktop targeting pack. CI builds and runs regression checks on GitHub's Windows Server 2022 and 2025 runner images; packaging runs once on 2025. This runner matrix does not replace runtime checks on Windows 10 and 11 desktop installations.

```powershell
dotnet restore --configfile NuGet.Config
dotnet build --no-restore
dotnet run --no-restore
dotnet run --project tests/DesktopTuner.Tests.csproj
```

An experimental desktop host can be launched alongside Explorer with `DesktopTuner.exe --desktop-host`. It shows user/public Desktop items over each monitor's configured Windows wallpaper, using Center, Tile, Stretch, Fit, Fill, or Span placement; it refreshes after desktop wallpaper settings change and as slideshow images advance. It includes root virtual items enumerated by the Windows desktop Shell, such as Network, Libraries, Control Panel, and Home or Gallery where available, while preserving This PC and Recycle Bin identities, and exposes their native Windows context menus alongside filesystem item verbs. It supports click/Ctrl/Shift multi-selection, Ctrl+A, Escape, and drag-to-select marquees with Ctrl-toggle; it opens entries on double-click, drags selected files out to other apps, and lets you freely position filesystem and virtual Shell icons by dragging them on the desktop or swapping their positions by dropping onto another icon. Dragging a selected group preserves its spacing, including mixed filesystem and Shell selections; only filesystem entries are included when dragging out to another app. Order and positions persist between runs in layouts keyed to each monitor; if a monitor disconnects, its icons move to the primary display while retaining their local coordinates. Older order-only layouts remain supported. The background menu can sort by name, item type, size, or modified date, align icons to a grid, or auto-arrange them per display; these preferences persist. Dropping files onto empty desktop space follows Explorer's move/copy rules: same-volume moves by default, cross-volume copies by default, Ctrl copies, and Shift moves. It refreshes when Desktop contents change. The background menu offers manual refresh plus a dynamic **New** submenu for registered ShellNew document templates, folder creation, and Windows' native desktop context menu through **Show more options**. Desktop item menus can pin filesystem folders, executable or shortcut targets, and supported Shell locations such as This PC, Network, Control Panel, and Recycle Bin to the replacement Start menu or taskbar.

`DesktopTuner.exe --shell-host` starts the experimental custom taskbars, Start menu, and desktop host together for Shell Launcher or Windows' per-user Custom User Interface policy. A supervisor launches the interactive shell in a worker process, retries one failed start, and forwards a folder or virtual Shell location request that arrived during startup after the worker signals readiness; after repeated failures it also clears the per-user policy when it still points to Desktop Tuner so the next sign-in uses Explorer. Desktop filesystem folders, This PC, and Recycle Bin open in Desktop Tuner Explorer while in shell-host mode; other discovered desktop namespace folders open in its companion namespace browser. `Win+E` opens the companion Explorer automatically in shell-host mode. `Win+T` and `Win+Shift+T` cycle taskbar controls forward or backward, continuing across connected displays in primary-first order. Filesystem-backed Start places use the same companion Explorer, and Network and Control Panel open in the namespace browser. If Explorer is already running, shell-host taskbars preserve and expose the best matching notification area on each display, and update the integration if Explorer starts or stops later; otherwise Desktop Tuner uses its own system controls and registers its own AppBar work area. Taskbar settings can configure and restore Shell Launcher for the current user on licensed Enterprise, Education, and IoT Enterprise editions after the optional Windows feature is enabled; Windows 11 Pro also supports the separate Custom User Interface policy. Setup, recovery, edition support, and remaining gaps are documented in [SHELL-INTEGRATION.md](SHELL-INTEGRATION.md).

Taskbar settings can optionally show current weather for a city or postal code you choose. Location search and weather requests use [Open-Meteo](https://open-meteo.com/) and [GeoNames](https://www.geonames.org/); weather is off by default, and the selected coordinates are sent only while the setting is enabled. The public API is for non-commercial use; commercial deployments need an appropriately licensed endpoint.

On Home and Pro as well as managed editions, choose **Start all-edition shell overlay** in Taskbar settings to start the custom desktop, Start menu, and taskbars for the current session. The custom taskbar overlays Explorer's main taskbar controls while its native notification area and third-party tray icons remain available on supported edge-aligned layouts. Enable **Start the shell overlay automatically when I sign in** from the overlay's Taskbar settings to create its per-user Startup shortcut. Exit from Taskbar settings or the taskbar menu to return to Explorer. This provides an all-edition replacement experience, but it is not a Winlogon shell replacement: Explorer remains available and its windows and shell services continue to run. See [SHELL-INTEGRATION.md](SHELL-INTEGRATION.md) for behavior details.

The app targets `net10.0-windows` and uses WPF with no third-party package dependencies. Each successful Windows workflow run publishes both a self-contained, single-file `win-x64` app and a per-user Windows installer as downloadable artifacts on that run's page. The installer does not require administrator privileges, adds a Start menu shortcut, and registers an uninstaller. The portable artifact can still be downloaded and extracted to run `DesktopTuner.exe` directly; neither option requires a separate .NET runtime install.
